# README.md

## Задача

Целью задания было создание нескольких примеров кода на языке C#, демонстрирующих работу с потоками и асинхронным программированием. Задания включали:

1. Запуск нескольких потоков и измерение времени выполнения.
2. Создание потокобезопасного счетчика.
3. Использование Task для асинхронного выполнения задач.
4. Параллельное вычисление факториала с использованием Parallel.For.
5. Асинхронная загрузка данных с веб-страниц.

## Используемые библиотеки

Для выполнения задания использовались следующие библиотеки:

- **System.Threading**: для работы с потоками.
- **System.Threading.Tasks**: для работы с асинхронными задачами и Task.
- **System.Net.Http**: для выполнения HTTP-запросов.

## Возникшие трудности

1. **Потокобезопасность**: При реализации счетчика возникли вопросы о том, как правильно синхронизировать доступ к переменной, чтобы избежать гонок данных. Решение с использованием блока lock помогло устранить эту проблему.

2. **Асинхронное программирование**: Понимание различий между async/await и обычными методами было важным для правильного использования асинхронных задач. Потребовалось время на изучение того, как обрабатывать исключения в асинхронных методах.

3. **Параллельные вычисления**: В примере с вычислением факториала необходимо было разобраться с использованием ConcurrentDictionary для хранения результатов, что обеспечивало потокобезопасный доступ к коллекции.

4. **HTTP-запросы**: При работе с HttpClient важно было учитывать, что его экземпляр должен использоваться повторно, а не создаваться каждый раз заново, чтобы избежать проблем с исчерпанием ресурсов.
