# README.md

## Задача

Необходимо разработать два пользовательских элемента управления в WPF:

1. **Индикатор**:
   - Круглой формы с рамкой.
   - Поддерживает два состояния: включен (зеленый цвет) и выключен (красный цвет).

2. **Кнопка**:
   - Круглая форма с квадратной рамкой со скругленными углами.
   - При нажатии воспроизводится анимация (изменение размера и цвета).
   - При нажатии на кнопку индикатор переключает свое состояние.

Элементы управления должны быть размещены на одном окне и взаимодействовать друг с другом.

## Используемые библиотеки

- **WPF (Windows Presentation Foundation)**:
  - Использовались стандартные библиотеки WPF для создания пользовательских элементов управления, анимации и привязки данных.
  - Основные пространства имен:
    - `System.Windows`
    - `System.Windows.Controls`
    - `System.Windows.Media`
    - `System.Windows.Media.Animation`

## Возникшие трудности

1. **Ошибка с замороженным `SolidColorBrush`**:
    Анимация цвета не работала после первого нажатия, так как объект `SolidColorBrush` был заморожен. Создан новый `SolidColorBrush`, если текущий заморожен.

2. **Анимация воспроизводилась только при первом нажатии**:
    После завершения анимации свойства оставались в конечном состоянии, и последующие анимации не применялись. Установлено свойство `FillBehavior = FillBehavior.Stop` для анимаций.

3. **Сложности с анимацией нескольких свойств одновременно**:
   Необходимо было анимировать и размер, и цвет кнопки одновременно. Использован `Storyboard` для управления несколькими анимациями.
