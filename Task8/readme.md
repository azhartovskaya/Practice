## Задача

Целью данного задания было создать приложение на WPF (Windows Presentation Foundation) с использованием C#, в котором должны быть реализованы следующие элементы управления и функциональность:

1. **ComboBox** для выбора цвета фона окна.
2. **TextBox** для отображения информации о действиях пользователя.
3. **ListBox** для выбора элементов, которые отображаются в TextBox.
4. **ProgressBar**, управляемый с помощью CheckBox.
5. **DatePicker** для выбора даты.
6. **Slider** для изменения размера шрифта в TextBox.
7. **Ellipse**, которую можно перемещать мышью по Canvas.
8. Несколько **кнопок**, которые добавляют текст в TextBox при нажатии.

## Используемые библиотеки

Для выполнения задания использовалась стандартная библиотека WPF, входящая в состав .NET Framework. В частности, применялись следующие пространства имен:

- System.Windows
- System.Windows.Controls
- System.Windows.Input
- System.Windows.Media

Также использовались стандартные компоненты WPF, такие как Window, Grid, StackPanel, ComboBox, Button, TextBox, ListBox, ProgressBar, DatePicker, Slider и Canvas.
